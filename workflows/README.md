# workflows/

> **Reusable workflows have moved to `.github/workflows/`** — GitHub's hard requirement for
> cross-repo `workflow_call` references (`uses: owner/repo/.github/workflows/<name>.yml@ref`).
> Subdirectories of `.github/workflows/` are not supported by GitHub.
>
> See [`.github/workflows/README.md`](../.github/workflows/README.md) for the full caller
> documentation and input surfaces.

No `.yml` files live here. This directory exists solely as a pointer.
